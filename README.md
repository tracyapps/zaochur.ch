# app/ — The Commons repository

> **Status:** The planning documents live in `docs/` below. Code begins in Phase 1, after the Phase 0 gates ([Roadmap](docs/06-roadmap.md)).

This folder is the public GitHub repository for the Zao Commons:

- **`docs/`** — the planning & foundations set ([start at the readme](docs/00-readme.md))
- **Frontend (Phase 1):** a PWA (Next.js/React — see [Technology](docs/07-technology.md))
- **Games:** ports of *doku (stardoku.app) and draw-tionary (draw-tionary.app) will live here as packages
- **Docs standard:** documentation is a deliverable — a stranger should be able to inherit this repo in a week (ETHICS-3/4)

Large design files and the image library live outside this repo, in the sibling folder `../branding-design/`, so the repository stays lean. Only finished, repo-relevant assets are copied in deliberately.

Nothing here is beyond the community's [non-negotiables](docs/02-non-negotiables.md). If code and covenant conflict, the code changes.
